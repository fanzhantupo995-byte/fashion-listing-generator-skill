# 参考模板目录说明

这里放**参考图**，不是成品。作用是给生成提供版式、配色、模块结构的依据。

**两条铁律：**
1. 按「用途 × 品类 × 模块」组织，**不为任何单个商品建目录**。参考图必须是可复用的版式样板。
2. 只提取版式与结构，不复制参考图里的商品内容、品牌标识和文案。

## 目录结构

```
参考模板/
├── 详情页/          详情页长图、单屏参考
│   ├── 女装/
│   ├── 男装/
│   ├── 童装/
│   └── 通用模块/    跨品类通用页：尺码表、面料说明、洗涤保养、售后保障
├── 主图/            主图参考（白底图、场景图、卖点图、细节图）
│   └── 通用/
└── 配色字体/        配色卡、色值表、字体样例
```

品类目录**是开放的**：出现新品类（内衣、家居服、鞋包、配饰、运动户外……）直接在 `详情页/` 和 `主图/` 下各建同名目录即可，不需要改 skill 的任何流程。skill 只认「目录名 = 品类」这一条约定。

## 文件命名

```
模块序号-模块名.jpg
01-首屏.jpg
05-面料细节.jpg
```

同一模块有多个风格版本 → `05-面料细节_A.jpg`、`05-面料细节_B.jpg`（A/B 是不同版式，不是新模块）。

主图参考命名：`主图-白底.jpg`、`主图-场景.jpg`、`主图-卖点.jpg`。

## 注意

- 只放图，不放 psd/ai 源文件（体积大且无法被读取）
- 单张图控制在 2MB 内，超长详情页长图建议切成单屏
- 拿不准归哪类的先放 `通用模块/` 或 `主图/通用/`，别随手新建目录
- 禁止用商品名当目录或文件名
