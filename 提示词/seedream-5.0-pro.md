# Seedream 5.0 Pro 提示词指导

服务适配附录。当本次项目确定使用 Seedream 5.0 Pro 生成时，由第五步载入本文件，按本文件的规则写提示词。

**本文件只讲 Seedream 5.0 Pro 的特殊之处。** 提示词的整体结构、修改项从哪来、模块取舍，全在 `SKILL.md` 第五步，本文件不重复。

---

## 一、先看硬约束（不知道会白跑钱）

| 事项 | 结论 | 后果 |
|------|------|------|
| 组图生成 | **不支持** | 提示词里写「一组六张」「生成一系列」→ 出不来或只出一张 |
| 流式输出 | 不支持 | 无影响 |
| 联网搜索 | 不支持 | 不写「搜索最新款」这类指令 |
| 参考图上限 | 10 张 | 母版 1 + SKU 若干，正常远够用 |
| 提示词长度 | 以当次服务 schema 为准 | 画面描述按母版复杂度编写，不设固定 300 字上限 |
| 提示词优化 | 支持标准 / 极速两档 | 标准档更慢但更好；批量出图可用极速档 |
| 分辨率档位 | 以服务 schema 为准 | TokenGo 2026-11-02 返回 `1k` / `2k` |
| 输出格式 | png / jpeg | 母版类需要留白的用 png |
| 水印 | 默认带「AI 生成」 | 交付图需要去掉就关掉 |
| 文字渲染 | 支持中文 | 不添加生成后自检环节 |

**最要紧的一条：不支持组图。** 本 skill 的主图计划天然是多张（每个搭配一张），因此**每张图独立生成、各自提交**，绝不在一条提示词里写「生成六张主图」。

## 二、提示词骨架

默认采用 `SKILL.md` 第五步的画面描述方法。先读当前母版和商品参考，再填写具体描述。

```
按 @image#1 的画面制作同版图片，商品对应 @image#2、@image#3。
画面描述：[当前母版的比例、背景、区域位置、大小关系和留白]。
[逐区描述商品的展示姿态、体积、开合、褶皱、遮挡与光影]。
[文字、品牌标识、边框、箭头等实际元素的位置和确认内容]。
商品特征以对应 SKU 图为准：[当前商品的关键款式、颜色与细节]。
所有图文位置、大小比例和留白贴近 @image#1，不重新设计排版。
```

### 段 1 · 参考图指代

母版是 `@image#1`，SKU 图依次是 `@image#2`、`@image#3`……

**`@image#N` 占位符已用于测试**（TokenGo + `doubao-seedream-5-0-pro`）。N 对应参考图数组下标，母版恒为 1。不能据此保证所有图片都不会漂移。

```
母版为 @image#1，商品参考为 @image#2、@image#3。
```

> 旧版本本文件写过「不要用 `@image#N`，官方文档统一用图号说法」。实测证明该结论不成立，已按出图证据更正。

参考图分工在开头写清楚即可。多个区域出现同款商品时，在画面描述中分别明确其呈现和对应参考。

### 段 2 · 当前母版的画面描述

先具体描述布局，再逐区写商品姿态、体积和层次。文字修改可单独写：

```
"原文案"改为"新文案"。
```

改文字时，**新文案用双引号包起来**。官方明确要求文字内容放在双引号中，中文直引号即可。

母版决定如何展示，SKU 决定款式与细节。不得只写「其余不变」代替画面描述，也不照搬 SKU 的平铺轮廓。

### 段 3 · 商品与固定元素约束

指出当前 SKU 的可见特征，并与母版的呈现状态区分。布局与固定元素的约束取自方案。

确有额外固定要求时才补充：

```
@image#1 的圆角边框、品牌标识、标题字号层级保持不变
```

具体锁哪几项，取自本项目的「固定元素清单」（方案第二步已和用户确认过）。母版里没有的元素不写。

### 完整示例

```
按 @image#1 的画面制作同版图片，商品对应 @image#2、@image#3。
画面描述：[先写整体布局，再逐区写商品呈现、图文与装饰]。
商品款式和细节以对应商品图为准，拍摄背景和摆放状态不沿用。
所有元素位置、大小比例、遮挡和留白贴近 @image#1。
```

以上是结构示意，方括号内容须按当次图片填写。具体商品、姿态和布局只属于当次提示词，不写成跨品类固定规则。

---

## 三、描述的边界

画面描述是复述当前母版可见的构图与呈现，不是另设计一套。允许写实际背景、区域比例、姿态、褶皱和光影，不写空泛审美词，不为贴合母版而给 SKU 添加不存在的结构。

---

## 四、文字渲染规则

- **新文案加双引号**：`"原文案"改为"新文案"`。
- **中文直引号**即可，不必用书名号。
- 文案长度和修改数量以已确认方案为准，不写死字数或两处修改上限。
- 仅当整版内容均已确认适用时才复用。参数表须使用当前商品已确认数据，不能为省略密集小字而直接沿用其他商品数字。
- 不添加生成后的文字复核或自动补正环节。

---

## 五、尺寸与比例

### 可用档位

| 参数 | 取值 |
|------|------|
| 比例 | 1:1、4:3、3:4、16:9、9:16、3:2、2:3、21:9、auto |
| 分辨率 | 服务 schema 决定；TokenGo 当前为 1K、2K |

详情页母版模块多为竖长条（3:4 或 9:16），主图母版多为 1:1。**按母版实际比例选档位**，不要默认 1:1。

### 非标准比例怎么办

母版模块的实际比例常常不在档位里（800×1200 是 2:3，但 790×860 是 11:12 这种）。此时：

1. 选**最接近的档位**生成。
2. 保留最接近档位的生成比例交付，不补边、不裁切回母版比例。
3. 在方案里记录母版比例与实际使用的档位；长图拼接只等比统一宽度。

方案阶段就要把这个限制写进「素材缺口与待确认项」，不要等出图才发现。

### 分辨率选择

- 只使用服务实际返回的档位，不默认传 `1.5K`。
- 纯文字海报类或需大幅裁切的模块用 2K。
- 批量出图、试错阶段可用 1K 省钱，定稿再补高分辨率。

## 六、反面写法对照

| 别写 | 改写成 |
|------|--------|
| 只写「按母版展示，其余不变」 | 按当前母版具体描述分区、姿态、体积、图文和留白 |
| 把它换成另一个颜色 | 明确商品参考图，保留母版对应区域的呈现状态 |
| 直接粘贴 SKU 的拍摄状态 | 商品结构来自 SKU，商品姿态与光影按母版描述 |
| 把字换一下 | "原文案"改为"新文案" |
| 生成一组六张搭配主图 | （拆成六条提示词，分别生成） |
| 高级感、精致细节、大师级品质 | （删掉。要么写具体的材质和结构，要么不写） |
| 它比原来更好看 | （删掉） |

---

## 七、结果保存

下载图片，保存参数和请求编号，直接交付。不执行生成结果自检或按画面效果自动补正重跑。

---

## 八、通用性

母版决定商品呈现形式，商品图决定商品特征。不默认使用「整体替换」，不把某张图的测试结果写成适用于所有商品的规则。
