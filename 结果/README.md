# 结果目录管理规则

## 一条铁律

**一个商品 = 一个项目文件夹。任何图都不许直接丢在 `结果/` 根目录下。**

## 项目文件夹命名

```
日期_品类_商品简称
2026-11-02_女装-黑色针织连衣裙
2026-11-03_男装-加厚卫衣
```

- 日期：`YYYY-MM-DD`，用开工当天
- 品类：自由填写（女装 / 男装 / 童装 / 内衣 / 家居服 / 鞋包……不限），与 `参考模板/` 下的品类目录对应
- 商品简称：2~8 字，不带空格和斜杠
- 同一天同商品出第二版 → 末尾加 `_v2`、`_v3`，**不新建文件夹**

## 项目文件夹内部（固定结构，不增不减）

```
2026-11-02_女装-黑色针织连衣裙/
├── 商品信息.md      # 品名、SKU、颜色款式、尺码、平台，开工前填
├── 方案.md          # 第二步产出的图片组成计划，用户确认后才生成
├── 01-素材/         # 用户给的原图、参考图，只读不改
├── 02-生成/         # 生成的单页图，按页码命名
└── 03-成品/         # 拼好的长图、裁切好的交付图
```

`01-素材/` 内按 SKU 再分子目录，图与 SKU 一一对应，不混放。

`02-生成/` 内命名：`01-首屏.jpg`、`02-面料卖点.jpg`…… 页码即顺序，禁止 `未命名-1.png` 这类名字。

## 目录本身不存垃圾

- 废弃方案不留在 `02-生成/`，移到项目内 `99-废弃/`，或整个项目挪到 `_历史/`
- `_项目模板/` 只读，开新项目时复制它，不要在里面直接干活

## 当前状态

- 本仓库不收录具体商品项目，项目数由使用者在本地维护。
