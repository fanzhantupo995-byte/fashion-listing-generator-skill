## 服装参考图清单

整体图与细节图都记录路径；每个颜色 SKU 保留自己的整体图，细节图绑定款式、来源 SKU、适用 SKU 和部位，生成时按本屏需要一同传入模型。

|------|----------|--------------|----------------|------------------------|------------------|
|      |          |              |                |                        | 未确认           |

同款结构、纹理和工艺一致的部位共用一套，差异部位单独补充；不同款式分别建套，不按颜色重复整套生成。目标配色由目标 SKU 整体图及已确认资料确定，不能沿用跨色细节图的来源配色，也不能将所有部件一律改成衣身颜色。

### 生成前与生成后确认记录

| SKU / 部位 | 细节及依据版本 | 本文内完整提示词编号/版本 | 生成前确认时间与用户原话 | 图片版本 | 生成后看图确认时间与用户原话 |
|------------|----------------|-------------------------------|--------------------------|----------|----------------------------|
|            |                |                               | 未确认                   |          | 未确认                     |

先确认细节、依据与完整提示词，再生成；看图确认后锁定版本，作为后续相关主图和详情页实际上传的产品细节基准参考图。描述或提示词变更时更新生成前确认，图片变更时重新看图确认，不沿用被替代版本的确认记录。

### 产品细节基准图生成提示词全文

按实际任务逐项填写完整正文，附任务编号、SKU/部位、参考图顺序、提示词版本、细节及依据、未知项和用户确认记录。本节在方案之前展示确认，不用摘要或占位文字代替。

本项目所需基准图全部确认可用并锁定前，不创建或编写方案文件、方案草稿或后续主图、模特图和详情页提示词。全部可用后，才复制方案模板，依据实际锁定版本制定方案、编写后续提示词并交用户确认。

所需基准按款式共用部位及必要差异项统计；用户对基准图的确认须同时覆盖明确列出的适用 SKU，不能将一个颜色的认可自动扩展到其他颜色。
