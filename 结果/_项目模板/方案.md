### 细节补建计划（缺少细节图时填写）

| SKU / 部位 | 细节描述与依据 | 未知项 | 基准图张数 / 费用 | 基准图路径与版本 | 确认状态 | 依赖的正式图片 |

生成后直接展示产品细节基准图与已记录的细节描述，由用户判断，不先读图审查。取得用户对具体版本的确认后，才生成依赖这些细节的正式图片。方案确认不替代产品细节基准图确认；生成依据和用户确认原话记入商品信息，不能把生成图标成实拍。

## 六、画面描述与输出规格

产品形态从本次母版的待替换实例提取，真实商品特征从替换产品基准图和产品细节基准图提取。固定元素留在方案，不逐项展开到提示词；不复用其他商品的姿态或固定修改数量。

| 屏号 | 替换实例与文字/元素修改 | 母版中的产品形态 | 替换产品对应与真实特征 | 母版比例 | 使用档位 |
|------|----------------|------------------------|-------------------|----------|----------|
|      |                |                        |                   |          |          |

比例不在模型档位内时选最接近档位，保留生成比例交付，不补边、不裁切。生成后仅检查文件、数量、尺寸和拼接顺序，直接展示给用户；不逐张读图、视觉比对或自动补正，正式成图不额外逐张等待审核。

### 每屏参考图顺序与细节约束

| 屏号 | 输入图号 | 文件路径 | 角色（母版/整体/细节） | 所属 SKU | 部位与约束内容 |
|------|----------|----------|-----------------------|----------|----------------|
|      |          |          |                       |          |                |

母版排第一，整体图随后，相关细节图最后；主图与模特图同样携带可见部位的细节参考。每屏统计母版、整体与细节图总数，确认不超过模型上限；缺图或超限的处理方式写入第五节。

提示词说明替换哪个实例、继承母版中的什么产品形态，以及替换产品基准图提供的真实特征。只列需修改的文字或元素，固定背景、品牌和版式等不描述，末尾用“其余保持不变”。不能只写“图1是母版”，也不增加生成后读图。

生成细节图填写用户已确认且未被替代的版本路径，并绑定对应描述；正式任务清单仅在基准图确认后建立，分阶段提交。
