### 细节补建计划（缺少细节图时填写）

| SKU / 部位 | 细节描述与依据 | 未知项 | 候选张数 / 费用 | 候选路径与版本 | 确认状态 | 依赖的正式图片 |
|------------|----------------|--------|-----------------|----------------|----------|----------------|
|            |                |        |                 |                | 待确认   |                |

先生成并展示候选图与细节描述，取得用户对具体版本的确认后，才生成依赖这些细节的正式图片。方案确认不替代候选图确认；生成依据和用户确认原话记入商品信息，不能把生成图标成实拍。

## 六、画面描述与生成参数

每屏描述从本次母版提取，不复用其他商品的布局或姿态。

| 屏号 | 整体布局与图文 | 各处商品姿态、体积与层次 | SKU 对应与关键特征 | 母版比例 | 使用档位 |
|------|----------------|------------------------|-------------------|----------|----------|
|      |                |                        |                   |          |          |

比例不在模型档位内时选最接近档位，保留生成比例交付，不补边、不裁切。不执行画面自检或自动补正。

### 每屏参考图顺序与细节约束

| 屏号 | 输入图号 | 文件路径 | 角色（母版/整体/细节） | 所属 SKU | 部位与约束内容 |
|------|----------|----------|-----------------------|----------|----------------|
|      |          |          |                       |          |                |

母版排第一，整体图随后，相关细节图最后；主图与模特图同样携带可见部位的细节参考。每屏统计母版、整体与细节图总数，确认不超过模型上限；缺图或超限的处理方式写入第五节。

生成细节图填写用户已确认且未被替代的版本路径，并绑定对应描述；正式任务清单仅在候选确认后建立，分阶段提交。
