# 服装主图与详情页生成 Skill

以已有主图、详情页为母版，结合新商品 SKU 图生成同版式商品图片。适用于不同服装品类，不绑定某件商品、品牌或固定页面结构。

## 核心方法

**母版提供产品展示形态，替换产品基准图提供真实商品特征，产品细节基准图约束对应部位。**

“产品细节基准图”是主图和详情页共用的产品局部参考，用于约束所有相关画面的商品细节；是否将它作为详情页特写成品展示，由页面方案另行决定。

读取母版中待替换商品的展示状态、姿态、体积、褶皱和相互关系，再结合替换产品基准图中的真实款式特征编写提示词。提示词重点写替换目标、母版产品形态、目标产品特征及实际文字修改；固定元素不展开描述，以“其余保持不变”概括。不把任何示例中的姿态、商品或修改数量固定成通用要求。

- 长图先按完整版块拆分；已有单屏图直接使用。
- 服装细节图与 SKU、部位绑定，直接传给模型。主图、模特图和详情页按可见部位携带相关细节图，减少局部结构、纹理、图案和工艺的偏差。
- 方案展示主图、详情页和产品细节基准图的实际完整提示词供用户确认。缺少细节图时，先确认细节、依据和提示词，再生成对应部位基准图交用户看图确认，锁定版本供后续相关图片统一上传参考。待确认图不进入正式生成，生成确认图保留来源标记。
- 先整理 SKU、资料缺口和组成方案，确认后生成；已有单张测试授权时先试图。
- 母版比例不在模型档位内时用最接近比例，保留该比例交付，不补边或裁切。
- 生成结果保存后直接展示给用户判断，不逐张读图、放大审图、视觉比对或自动纠错重跑；只检查文件、数量、尺寸和拼接顺序。生成前必要的素材读取保留，已有描述和确认记录直接复用。
- 本仓库提供通用制作流程、画面描述方法、母版拆分辅助脚本和空白项目模板。实际生图能力由使用环境提供，不随 skill 分发。

## 安装与使用

将本仓库克隆到本机的 Skill 目录，文件夹名建议为 `fashion-listing-generator`，入口是 [SKILL.md](SKILL.md)。例如：

```bash
git clone https://github.com/fanzhantupo995-byte/fashion-listing-generator-skill.git \
  ~/.codex/skills/fashion-listing-generator
```

在新的 Agent 会话中提供母版图、SKU 整体图和已有服装细节图，并请求：

```text
使用 fashion-listing-generator，按母版制作这件商品的主图和详情页。
先用画面描述方案试一张主图。
附带细节图已按 SKU 和部位标记，请作为生成参考约束对应部位。
没有细节图的部位，请先依据产品资料描述细节并生成产品细节基准图，给我确认后再用于主图和详情页。
```

流程与提示词方法见 [SKILL.md](SKILL.md)。本 skill 不安装或配置生图工具，不提供调用命令、服务适配或执行接口。当前环境已有生图能力时按流程执行；没有时交付参考图清单、画面描述和待生成任务。

## 文件

| 路径 | 用途 |
|---|---|
| `SKILL.md` | 输入、母版解析、方案、画面描述、生成与交付 |
| `参考模板/` | 模板目录规则和空白店铺规范 |
| `结果/_项目模板/` | 商品信息与组成方案空表 |
| `脚本/split_sections.py` | 长图导航和人工确定边界后的切分 |

## 母版拆分辅助

需要 Python 3；长图拆分依赖 Pillow：

```bash
python3 -m pip install -r requirements.txt
python3 脚本/split_sections.py scan 输入长图.jpg 临时拆分目录
```

该脚本只处理本地图片，不执行生图。

每屏整理“母版 → 替换产品基准图（SKU 整体图）→ 相关产品细节基准图”的参考清单，明确替换实例、产品形态及实际产品特征。缺少细节图时，先通过外部能力生成产品细节基准图供用户确认；确认后将对应版本纳入正式成图参考。
